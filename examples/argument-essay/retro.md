# retro — 설득하는 글, 어떻게 짜여 있을까? (고1 공통영어, 3/12차시)

## 걸린 게이트와 고친 방법
1. **S2-BULLET (49자>48자)** — summary 항목에 영어 신호말 네 개를 나열해 글자 수 초과. 신호말 목록을 "같은 신호말이 짜임을 알려 준다"로 줄여 해결.
2. **B6-PAGES (lesson-plan 4쪽>3쪽) / B6-LAST (마지막 쪽 17%)** — 지도안 `flow`가 8행이라 표가 길어져 4쪽으로 밀림. 도입 2행, 전개의 "짝 활동"+"이해 확인" 2행을 각각 합쳐 6행으로 줄이고, 평가 계획 3행 중 목표1·2를 다루던 두 행을 하나로 합쳐 표 높이를 줄였다. `flow.minutes` 합은 항상 50분으로 재확인.
3. **B6-FILL (worksheet 1쪽 51%<55%)** — 지문 전체(cloze)를 한 덩어리 `concept` 문항으로 넣었더니, 쪼갤 수 없는 큰 블록이 통째로 다음 쪽으로 밀려 1쪽이 절반만 채워짐. 지문을 "주장+근거" / "반론과 재반박+결론" 두 개의 `concept` 문항으로 나눠 페이지네이션이 더 촘촘히 채우도록 해결.
4. **(게이트가 못 잡은 문제, 육안 검수에서 발견)** — 표지(slide-01)와 개념 슬라이드(slide-05)에서 `v-accent`(진한 보라) 박스 위에 `v-label-a`(진한 보라 텍스트, `--accent-ink`)를 얹어 글자가 거의 안 보이는 저대비 문제가 있었다. B3 게이트는 SVG `<rect>` 채움을 CSS `backgroundColor`로 인식하지 못해 이 대비 문제를 잡지 못했다(`bgOf()`가 SVG fill을 못 읽고 종이 배경과 대조함). 진단 슬라이드(slide-06)에서 이미 쓰던 "연한 배경(v-mid/v-paper2/v-paper3) + 왼쪽 강조색 얇은 띠(v-accent/v-ink) + 진한 글자(v-label/v-label-a)" 패턴으로 cover·concept 삽화를 다시 그려 해결.

## 스킬 사용 소감
- `references/design.md`의 SVG 규칙(선 클래스 vs 채움 클래스 구분, viewBox를 그림에 맞추기)을 지키니 B2/B5 게이트는 첫 시도에 바로 통과했다.
- 반면 "텍스트를 얹을 배경 채움 클래스"에 대한 규칙은 문서에 없었고, 게이트도 SVG 내부 대비를 실제로 측정하지 못해 위 4번 문제를 스스로 발견하지 못했다. 캡처 육안 검수 단계가 없었다면 이 결함이 그대로 나갈 뻔했다 — "게이트 통과 후 반드시 캡처를 본다"는 절차의 필요성을 그대로 보여준 사례.

## 다음에 처음부터 다르게 할 것
- 삽화에서 "박스 채움 위에 텍스트를 얹는" 구성을 계획할 때는 처음부터 v-accent/v-ink/v-muted 같은 진한 채움 클래스는 얇은 강조 띠나 선으로만 쓰고, 텍스트가 올라가는 배경은 항상 v-mid/v-soft/v-paper2/v-paper3 같은 연한 채움만 쓰기로 먼저 정해 놓으면 육안 검수에서 다시 고칠 필요가 없다.
- 지도안 `flow`나 활동지의 긴 지문처럼 "쪼갤 수 없는 큰 블록"이 들어갈 걸 알면, 처음부터 문항/행을 적당히 나눠 페이지네이션 여유를 만들어 두는 게 낫다.

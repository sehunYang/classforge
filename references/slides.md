# 슬라이드 유형 카탈로그와 수업 흐름

15개 유형 밖의 레이아웃은 만들지 않는다. 한 유형이 교실에서 하는 일이 정해져 있다.

| 유형 | 교실에서 하는 일 | 좋은 사용 | 피할 것 |
|---|---|---|---|
| `cover` | 수업 시작, 주제 제시 | 질문형 제목 + 주제를 상징하는 삽화 1개 | 삽화 없이 제목만 |
| `goals` | 학습 목표와 중심 질문 공유 | `reveal:true`로 목표를 하나씩 읽기, `question`에 수업 끝에 다시 답할 질문 | 목표 4개 이상 |
| `hook` | 동기 유발, 오개념 끌어내기 | 학생이 답을 예상하게 만드는 질문 + 대비되는 두 장면 삽화 | 답을 바로 알려 주는 lead |
| `chapter` | 활동/개념 전환 알림 | 수업을 2~3부로 나눌 때 각 부 시작에 | 4장 이상(흐름이 끊김) |
| `concept` | 개념 설명 | 핵심 메시지형 제목 + 2~3개 포인트 + 오른쪽 설명 삽화 | 포인트마다 긴 설명 |
| `compare` | 두 경우 대비 | "A라면 / B라면" 대칭 구조, 오른쪽이 정답 쪽 | 좌우 항목 수가 다름 |
| `steps` | 실험·풀이·활동 절차 | 단계마다 작은 삽화(`steps[].visual`), 3~4단계 | 삽화 없이 글만(화면 위쪽이 비어 보임) |
| `diagram` | 큰 그림 하나로 설명 | 실험 장치, 구조도, 지도, 그래프 | 라벨이 작은 그림 |
| `bignum` | 인상적인 수치 하나 | 교과서·공공 자료의 수치 + `visual`로 의미 그림 | 출처 없는 수치 |
| `quiz` | 형성평가(이해 확인) | 오개념을 선택지로 넣기, 손가락/보드로 동시 응답 | 정답이 너무 뻔한 선택지 |
| `activity` | 모둠/개인 활동 지시 | 역할·순서·결과물·시간을 한 화면에 | 5단계 이상 지시 |
| `vocab` | 핵심 용어 | 2~4개, 뜻은 학생 말로 | 사전식 긴 정의 |
| `timeline` | 역사·과정의 시간 순서 | 3~5개 사건 | 날짜 없이 순서만 |
| `summary` | 정리 | 목표에 대응하는 2~3문장, `next`로 다음 차시 예고 | 새로운 내용 추가 |
| `passage` | 읽기 지문 제시 | 지문을 기능별 덩어리(주장·근거…)로 나눠 `label`을 달고 핵심 덩어리에 `hot` | 지문을 SVG 글자로 그리기(조판이 깨짐) |
| `exit` | 나가기 질문(exit ticket) | 오늘 배운 낱말을 써서 설명하게 하는 질문 | 예/아니오 질문 |

## 권장 흐름 (40~50분, 12~16장)

**개념 탐구형 (과학·사회·수학 개념)**
```
cover → goals → hook → vocab → concept(+visual) → diagram → quiz
      → chapter → compare → steps(+icons) → activity → quiz → summary → exit
```

**문제 해결형 (수학·정보)**
```
cover → goals → hook(생활 속 문제) → concept(원리) → steps(풀이 절차) → quiz
      → activity(짝 문제 풀이) → compare(흔한 실수 vs 바른 풀이) → quiz → summary → exit
```

**읽기·토의형 (국어·도덕·사회)**
```
cover → goals → hook(장면 제시) → vocab → concept(읽기 전략) → activity(모둠 읽기)
      → compare(두 관점) → quiz → activity(토의) → summary → exit
```

**역사형**
```
cover → goals → hook(사료/장면) → timeline → concept(원인) → bignum(수치 자료) → quiz
      → compare(이전 vs 이후) → activity → summary → exit
```

**증거 중심 탐구형 (evidence, `meta.profile:"evidence"` — 원작 교사의 스타일, 과학·이과 개념 수업)**
소단원 하나(현상 → 정의 → 증거 → 활용 → 확인)를 한 바퀴 도는 원작 교사 자료의 반복 패턴을, 45~50분 단일 차시(12~16장)로 압축한 흐름. 소단원이 둘이면 `chapter`로 나눠 이 루프를 두 번 돈다.
```
cover → goals → hook(현상/역사 도입) → concept(정의, 명사구 제목 허용) → diagram(핵심 실험·증거 — 공식이 있었다면 그 근거)
      → compare(대립 관점 대칭 비교) → quiz(비교 판정) → chapter → concept(응용 개념, +수식) → steps(적용 절차) → quiz → summary → exit
```
- 공식이 있는 `concept` 바로 옆(앞뒤 중 하나)에 그 근거를 보여 주는 `diagram`/`steps`를 반드시 붙인다([[pedagogy.md]] 10번).
- **`compare` 바로 다음 장은 반드시 그 대립을 판정하는 증거 슬라이드**여야 한다 — 위 흐름의 `compare(대립 관점 대칭 비교) → quiz(비교 판정)`처럼, `compare`는 항상 그 자리에서 답을 주지 않고(좌우를 대칭·중립으로 두고 — `evidence` 프로파일에서는 색으로도 미리 알려주지 않는다) 바로 다음 슬라이드(`diagram`/`steps`/`quiz`의 `explain`)가 실험 결과로 판정한다. `compare` 뒤에 무관한 슬라이드(예: `chapter`, 새 `vocab`)를 끼우지 않는다.
- **개념 슬라이드 한 장에 정의 하나** — `concept`의 `points`는 정확히 1개만 쓴다(2개 이상이면 **E1-ONEDEF**로 실패). 짝을 이루는 두 개념(보강간섭/상쇄간섭, 전반사/굴절 같은 쌍)을 한 `concept`의 `points` 두 항목으로 몰아넣지 말고, `concept`를 두 장으로 나눈다(각 장에 명사구 제목 하나 + 그 정의만). 설명이 더 필요하면 `lead`나 발표자 노트로 옮긴다.
- 오개념·역사 도입을 다루는 `hook`/`concept`는 노트 6문장까지 허용(아래 "발표자 노트" 예외).
- **스포일러 금지** — `compare` 앞에 오는 `hook`·역사 도입·`timeline`은 풀리지 않은 수수께끼로 끝나야 한다. "그래서 무엇이 맞았는지"를 알려주는 사건(설명·해결)은 `compare` 판정 **뒤**에만 둔다(`timeline`이면 다음 소단원에서). 게이트 **E1-SPOILER**가 `compare` 앞 `timeline`의 마지막 사건에 "설명/해결/밝혀"가 있으면 경고한다([[pedagogy.md]] 10번).

**문제풀이 차시 (evidence 프로파일의 복습형 대안 흐름 — 형성평가 위주로 요청받았을 때)**
개념 설명 없이 이미 배운 내용을 확인만 하는 차시. 소단원(또는 배운 주제)마다 `chapter`로 구획하고 그 뒤에 `quiz`를 3~5개 연속 배치한다 — 개념은 한 장에 하나씩 쪼개던 평소 원칙과 반대로, **이 흐름에서만 퀴즈를 몰아서** 낸다.
```
cover → goals → chapter(주제 1) → quiz × 3~5 → chapter(주제 2) → quiz × 3~5 → summary → exit
```
- 주제(소단원) 수 × (퀴즈 4~5 + chapter 1)이 12~16장을 넘지 않게 주제 수를 2~3개로 제한한다.
- 오답 선택지는 실제 오개념으로 채운다(평소 원칙과 동일, [[pedagogy.md]] 5번).
- 이 흐름은 "확인하는 시간"이 목적이므로 새 개념(`vocab`·`concept`)을 섞지 않는다.

## 리듬
- 글 중심 슬라이드 2장이 이어지면 다음은 삽화·퀴즈·활동으로 바꾼다.
- 10분에 한 번은 학생이 무엇인가를 하게 한다(quiz 또는 activity).
- `reveal:true`는 goals, concept, vocab, summary처럼 "하나씩 이야기할" 슬라이드에만.
- 슬라이드 수 ≈ 수업 분 ÷ 3.

## 발표자 노트(`notes`) 쓰는 법
교사가 그 화면에서 **말할 것, 물어볼 것(발문), 주의할 오개념**을 2~4문장으로. 화면 글을 반복하지 않는다.
- 예외: 역사적 맥락이나 오개념을 다루는 `hook`/`concept` 슬라이드는 **6문장까지** 허용한다(짧은 발문으로는 "그 시대엔 왜 그렇게 생각했는지" 서사가 끊긴다 — [[pedagogy.md]] 10번, 근거: 원작 교사 자료의 역사·오개념 슬라이드 발표자 노트). 화면 글을 그대로 읽는 대본이 되지 않게, 여전히 "말할 것"으로 쓴다. 예(hook, 4~6문장): "물속의 젓가락이 왜 꺾여 보이는지 자유롭게 예상하게 한다. 옛날 사람들도 이 현상을 보고 빛이 물체를 통과하며 힘을 받는다고 생각했다. 그 생각이 왜 그럴듯했는지 먼저 인정해 준다. 오늘 배울 원리는 이 현상을 속력 차이라는 숫자로 정확히 설명한다는 것을 예고한다. 답은 바로 알려주지 않는다."
